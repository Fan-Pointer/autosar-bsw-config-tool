## 1. 交付清单

### A. 参考数据层基础设施（首批随 DBC 交付）

| 编号 | 交付内容 |
|---|---|
| A1 | 独立存储键 `autosar-reference-data`（清单 + 各文件解析产物）；写入沿 assertWritable 守卫纪律；删除参考文件不触碰配置库 |
| A2 | 导入入口：模块管理/起始页「导入参考数据」——选文件 → 解析 → 预览（节点/报文/信号计数）→ 确认入库；**取消零写入**；重复文件按内容 hash 去重提示 |
| A3 | 工作区「参考数据」查看面板：列表 + 搜索（沿 GlobalSearch 交互口径）；大文件（数千信号）按需渲染 |
| A4 | 相关模块编辑时的「参考数据」浏览视图（只读参照，不自动填值、不建立自动绑定） |

| B2 | 结构化展示：报文 → 信号两级列表 + 值表；单测：官方样例 DBC + 畸形样例（错误分隔符/缺字段）拒绝并给原因 |
