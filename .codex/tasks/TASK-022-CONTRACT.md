## 1. 交付清单

### A. G31 多实例列表视图

| 编号 | 交付内容 |
|---|---|
| A1 | 多实例容器（multiplicity 上限>1 或 0 实例）参数区提供**列表视图**：勾选列 / 序号 / containerName（固定列，可排序）/ 各参数为列（可排序）；与既有表单视图并存可切换（默认形态报告说明选型） |
| A2 | **列设置弹窗**「选择显示配置项」：containerName 固定不可取消；每参数一复选框默认全选；列偏好按容器定义记忆（会话内） |

1. `npm run build` 通过；`test:verify` 守卫通过且 **346 基线 0 fail** 不回退（撤销满载抖动按既定口径隔离复跑）。
