# 用户新增交互要求：右键直接选择子容器

来源：2026-11-06 当前 Codex 主对话。用户明确要求恢复自动开发，先提交 TASK-012 交 WorkBuddy 评审，通过后继续分阶段开发。

用户原话：**“子容器的添加应该是上图这样，右键直接显示该容器下的所有子容器供选择”**。

截图见 `../references/child-menu-20261106.png`。图中在实例节点右键，一级菜单含 New / Del Element / ReName Element；New 右侧直接展开该父容器的全部子定义，部分条目置灰。图示模块名仅为参考，不要求本项目硬编码或扩大模块支持范围。

交接给 WorkBuddy 的设计输入（待其并入契约）：

1. 在配置树实例节点右键，提供“新建”二级菜单，直接列出当前父容器定义中的所有子容器名称；选择可用项立即创建实例，不再先打开另一个选择弹窗。
2. 所有候选来自 BSWMD 元数据；达到 multiplicity 上限、CHOICE 互斥、只读等不能新增的项仍可见但禁用，说明具体原因。
3. 创建位置必须对应右键节点，不能误用此前选中的其他节点；成功后选中新实例，保持单步撤销/重做。
4. 项目实际有大量子定义，菜单须可滚动、贴合视口边界，并支持键盘进入/退出；无子定义给出明确空状态。
5. 删除、重命名与原有实例规则沿用，不因菜单变更绕过定义或引用约束。

本要求不混入已完成的 TASK-012 恢复功能提交。请 WorkBuddy 结合 S4 实例生命周期入口收敛安排契约和验收；若决定提前独立小阶段，由 WorkBuddy 明确下发，Codex 再实施。
