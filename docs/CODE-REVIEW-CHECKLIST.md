# 代码评审检查单（Code Review Checklist）

> 适用于 Codex 提交的每轮代码评审。按 🔴 阻塞 / 🟠 重要 / 🟡 建议 分级。

## 一、代码质量

### 🔴 阻塞项
- [ ] 存在 TypeScript 类型错误（`any` 滥用、未定义类型）
- [ ] 存在 ESLint 错误（必须修复才能合并）
- [ ] 直接修改了 `node_modules` 或第三方库文件
- [ ] 存在安全漏洞（XSS、SQL 注入——虽纯前端但模板注入需注意）
- [ ] 内存泄漏风险（事件监听器未清理、订阅未取消）

### 🟠 重要项
- [ ] 复杂逻辑缺少注释（条件联动、验证规则等）
- [ ] 函数过长（> 50 行，考虑拆分）
- [ ] 嵌套过深（> 4 层，考虑提取）
- [ ] 魔法数字（应提取为常量或枚举）
- [ ] 重复代码（DRY 原则）

### 🟡 建议项
- [ ] 变量命名不规范
- [ ] 导入路径是否使用别名（`@/`）
- [ ] 错误处理是否完整
- [ ] 边界条件处理

## 二、功能完整性

### 🔴 阻塞项
- [ ] 功能与需求不符（对照 REQUIREMENTS.md）
- [ ] 未处理必填字段验证
- [ ] 引用完整性检查缺失
- [ ] ARXML 导出不符合规范
- [ ] 数据持久化失败（无法恢复）

### 🟠 重要项
- [ ] 错误提示不明确
- [ ] 未处理边界值（如 EventId 超出 65535）
- [ ] 条件字段联动逻辑不完整
- [ ] 批量操作数据不一致

### 🟡 建议项
- [ ] 缺少加载状态提示
- [ ] 缺少空状态处理
- [ ] 可访问性（A11y）考虑不足

## 三、性能

### 🔴 阻塞项
- [ ] 存在内存泄漏
- [ ] 大量数据渲染导致卡顿（>1000 DTC 时）

### 🟠 重要项
- [ ] 未使用虚拟滚动（列表 > 100 项）
- [ ] 未使用防抖/节流（输入、搜索等）
- [ ] 不必要的重新渲染（未使用 computed、watch 优化）

### 🟡 建议项
- [ ] 大对象未做结构化克隆优化
- [ ] 图片/资源未优化

## 四、UI/UX

### 🔴 阻塞项
- [ ] 响应式布局在 1366x768 下无法正常使用
- [ ] 表单验证错误未实时提示

### 🟠 重要项
- [ ] 主题切换（暗色/亮色）不完整
- [ ] 快捷键不符合约定（Ctrl+Z/Y）
- [ ] 自动保存冲突处理

### 🟡 建议项
- [ ] 交互动画过于复杂
- [ ] 缺少新手引导

## 五、测试覆盖率

| 模块 | 当前覆盖率 | 目标覆盖率 |
|------|------------|------------|
| 数据模型 | - | ≥ 80% |
| Store | - | ≥ 60% |
| 工具函数 | - | ≥ 80% |
| 组件 | - | ≥ 50% |

## 六、文档更新

### 🟠 重要项
- [ ] 新增组件/函数未更新 README
- [ ] API 变更未更新文档
- [ ] CHANGELOG 未更新

## 七、安全审查

### 🔴 阻塞项（零容忍）
- [ ] 将配置数据发送到远程 API
- [ ] 硬编码密钥/凭证
- [ ] XXE 漏洞（ARXML 导入）
- [ ] XSS 漏洞（用户输入未转义）

### 🟠 重要项
- [ ] LocalStorage 未加密（可选但建议）
- [ ] 文件上传未校验类型/大小

## 评审输出格式

```
## 评审结果

### 🔴 阻塞问题 (必须修复)
| # | 位置 | 问题描述 | 影响 | 修复建议 |
|---|------|----------|------|----------|
| 1 | src/... | ... | ... | ... |

### 🟠 重要问题 (建议修复)
| # | 位置 | 问题描述 | 影响 | 修复建议 |
|---|------|----------|------|----------|

### 🟡 优化建议 (可选)
| # | 位置 | 问题描述 | 建议 |
|---|------|----------|------|
```

---

**使用说明**：
1. Codex 提交 PR 后，锻码师按此清单逐项过
2. 输出评审结果到 PR Comment
3. 🔴 阻塞问题必须修复才能合并
4. 🟠 重要问题建议修复
5. 🟡 优化建议后续迭代处理
