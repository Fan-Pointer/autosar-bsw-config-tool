## 1. 信息架构（修正 G09 术语）

```
首页（Home）
├─ 新建配置集          ──→ 工作区
├─ 导入配置数据         ──→ 导入预览（JSON/ECUC ARXML）
├─ 打开示例（官方 4.4.0 Dem）──→ 工作区
└─ 最近配置集（IndexedDB 兼容条目；隔离条目显示锁定态）

工作区（Workspace，三栏保留——结构已验证有效）
├─ 左：导航树（配置集列表 → 模块定义容器/实例混排）
│   └─ 定义节点 ⊞ / 实例节点 i / 状态点（错误●橙/齐全●绿）
├─ 中：顶级容器页签（…溢出）+ 容器树 + 工具栏（＋添加 / 克隆 / 删除 / 排序↑↓）
├─ 右：参数表单（面包屑 + 实例名 + 参数行）＋ 底部问题面板（可收起）
├─ 顶：保存状态 · 校验状态 · 全局搜索 · 撤销/重做 · 导入 · 导出 · 主题
└─ 数据安全横幅（仅锁定态显示，见 S0）

隐藏/移除（G09/G01 处置）：/wizard、/import-export 占位路由；RTE/输入/输出文件空分支；
右键「工程管理/自动计算」等未核实占位项
```

术语统一：**配置集**（=一个模块的配置实例，原「工程」）；**模块定义**（BSWMD）；**隔离条目**（quarantined）。界面不再出现"工程"称谓。

## 2. 核心流程与状态

### 2.1 恢复流程（S1）

```
启动 → 读 v3 库 → 逐条恢复
  ├─ 兼容条目 → 正常编辑（状态：已恢复）
  ├─ 失配条目 → 检出即建永久快照（写锁前）→ 入隔离区 → 建立写锁
  │     └─ 用户可选：导出原始数据 / 隔离详情 / 用旧定义只读打开 / 暂时搁置
  └─ 全兼容 → 无锁无快照，行为与现状一致
```

### 2.2 编辑→输出闭环（S3 定语义）

```
编辑 ──→ 校验（普通检查：类型/值域/引用/必填未确认）
   │        ↓ 同一闸门 isOutputReady(config)
   ├─ 通过 → 导出 ARXML（r4.0）/ JSON / CSV ＆ 生成 C —— 输出一致
   └─ 不通过 → 问题面板列出：严重度/路径/原因/[定位] → 修复 → 重验
   撤销链覆盖：编辑、批量、引用选择、CHOICE 切换（取消零写入）
```

### 2.3 状态机（页面级）

| 状态 | 来源 | 表现 |
|---|---|---|
| 已保存 / 保存中 / 保存失败（脏） | G19 | 顶部持久状态点；失败重试按钮；自动保存不绕 S1 锁 |
| 校验通过 / N 个问题 | G03/G14 | 顶部计数 + 问题面板 |
| 输出就绪 / 被 N 项阻断 | G03 | 导出按钮旁计数，点击展开面板 |
| 数据锁定（只读保护） | S1 | 黄色横幅 + 四动作，锁定时不显示"保存成功"类误导反馈 |

## 4. 交互红线

1. 引用/CHOICE 的**取消必须零写入**（L04/L05 已证实的缺陷语义）
2. 锁定态**不得出现任何"已保存"类误导反馈**；所有被拒写操作给出原因
3. 长文本（枚举/说明）不得只靠 tooltip；字段帮助入口含定义路径/范围/说明（G10）
4. 新手不依赖右键也能完成主流程（G08/G24）
5. 每个破坏性动作（删除/放弃隔离条目/删除快照）必须先满足其前置（导出确认/二次确认）且有撤销或明确不可逆提示
