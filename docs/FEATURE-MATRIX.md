## 三、差距与需求建议（按优先级）

### P0 — 本轮已纳入 TASK-011
1. 右键「添加子容器」弹窗优化：列表 + 搜索 + 约束徽标 + 已实例计数 + 必选置顶（C1–C4）。
2. 测试适配官方 Dem 定义（112 失败修复）。

### P1 — 建议下一轮（TASK-012 候选）
3. **容器实例工具栏图标组**：补「上移/下移排序」（参考站 ⇅ 图标），与拖拽排序（TASK-010 B4）合并做。
4. **模块协议栈分组**：新增一份模块分组元数据（CAN COM / COM Stack / System Services / UDS / Memory …），树按分组渲染；官方 98 模块都归得进组。
5. **外部引用（FOREIGN/INSTANCE）的展示**：TASK-011 B4 已列，验证落地。

### P2 — 产品化阶段
6. 验证/生成结果视图（对应「输出文件」节点，展示生成文件清单与可下载）。
7. 实时校验开关。
8. 历史版本快照（本地即可：每次保存留快照，可回滚）。
9. 多语言（i18n 骨架）。
10. 工程日志 / 笔记。

### 不做
- 云端协同、分享、公告（纯本地工具定位）。
