### 区域尺寸与行为

| 区域 | 尺寸 | 行为 |
|---|---|---|
| 顶栏 | 高 ~38px | 左：logo + 产品名 + 一组无文字图标；右：`首页 公告` / `简体中文 ▾` / 头像 |
| 模块页签行 | 高 ~34px | 每个已打开模块一个页签，**可关闭（×）**；当前页签有下边框 |
| 工程目录（左） | 宽 **212px**，可拖拽、可折叠（`‹` 按钮） | 纵向树：工程根 → `模块管理`（分组 → 模块）→ `RTE` / `AUTOSAR文件` / `输出文件` / `输入文件` |
| 模块配置树（中） | 宽 **240px**，可拖拽 | 从上到下四段：**顶级容器页签行** → **树工具栏**（列表/↑/↓/＋） → **搜索框** → **容器-实例混合树** |
| 参数表单（右） | 占满剩余 | **面包屑** → **实例名称输入** → 分割线 → **参数行列表** |

> 树节点行高 ~28–30px；表单行高 ~50px、输入框高 ~32px、宽 ~270px（截图估计，验收用同视口并排比对）。

## 二、已展示的交互（逐条有图为证）

### 2.1 两级页签（职责不同，不可合并）

| 层级 | 位置 | 内容 | 依据 |
|---|---|---|---|
| 一级：模块页签 | 顶栏下一行 | `CanIf(AUTO…` 可关闭 | 02 |
| 二级：顶级容器页签 | 中间列顶部 | `CanIfCtlrDrvCfg` / `CanIfDisp…`；当前项**蓝色下划线** | 02 |
| 二级溢出 | 中间列 | 宽度不足时出现 `…` 按钮，点开**竖排下拉**列出被隐藏的顶级容器：`CanIfDispatchCfg / CanIfInitCfg / CanIfPrivateCfg / CanIfPublicCfg / CanIfTrcvDrvCfg` | 03 |

### 2.2 容器-实例混合树

- 容器节点与实例节点**同树混排**，容器可展开
- 实例节点前置 **`i` 图标**
- 选中实例 = **浅蓝底 + 蓝字**
- 节点文字为 `定义短名` 与 `实例短名`（如 `CanIfCtlrDrvCfg` → `CanIfCtlrDrvCfg_0`）
- 树上方工具按钮：`列表视图` / `上移` / `下移` / `新增`
- 搜索框 placeholder：`请输入文字搜索`

### 2.3 参数行（本轮最关键的结构发现）

单行 = `[可选复选框] + 标签 + 必填红标 + 控件 + [后缀控件]`

| 元素 | 观察 |
|---|---|
| **可选参数复选框** | 部分行标签左侧有方框（`CanIfRxPduUserRxIndicationUL` / `…Name` / `…CanId` / `…CanIdMask`），**勾选才启用**；未勾选时右侧输入**灰底禁用** |
| 必填标记 | 必填行在标签右侧有**红色圆形标记**（形似 ⊗/*），与复选框**互斥出现** |
| 控件类型 | ① 开关（`CanIfCtlrWakeupSupport`、`CanIfRxPduReadData`）② 下拉 `请选择`（`…CanIdType`）③ 文本输入（`…UserRxIndicationName`）④ **数字输入 + `DEC` 进制下拉**（`…CanId`、`…Dlc`、`…Id`）⑤ **引用输入 `--` + 右侧选择图标按钮**（`…HrhIdRef`、`…Ref`） |
| 后缀图标 | 部分数字行尾有额外汇算/表达式按钮（`⛭` 状） |
| 分组 | 用**细横线**分段（实例名称 与 参数之间、参数与引用之间），无卡片无边框 |
| 禁用态 | 灰底 + 灰字，指针不可编辑 |

### 2.4 工程树右键菜单（05）

在工程根上右键，菜单项依次：

`新建 ▸` / `工程管理 ▸` / `模块管理 ▸` / —— / `✅ 代码验证` / `✅ 代码生成` / `导入 ▸` / `导出 ▸` / —— / `自动计算` / `关闭工程`

> 子菜单内容仅 `新建` 展示了 `新建工程` 一项，其余未展开 → 标未核实。

居中模态，约 1000×600：

- 左：**可搜索的模块树**，按类别分组（System Services / COM Stack / Mcal…），每项带复选框，标题栏有全选 + `0/32` 计数

## 三、必须写清的边界

| 项 | 结论 |
|---|---|
| 数据来源 | 仍由 **BSWMD 驱动**（`bswmd/*_bswmd.json`）。截图里的 CanIf/Dem 只是参考内容，**不得在 UI 写死任何模块字段** |
| 模块范围 | 菜单里列了 11 个模块 ≠ 我们要实现全部 BSW。本轮只做**通用水位**：能把任意 BSWMD 模块渲染成这套形态 |
| 配色 | 可调。默认沿用浅底 + 蓝选中，保证结构比对优先 |
| 品牌 | **不复刻** `EasySAR` 名称、logo、头像、`首页/公告` 内容 |
| 后端 | EasySAR 是服务端驱动；我们纯前端，接口名只作命名参考，不实现服务 |

## 五、与我们现有实现的差距（改造清单）

| # | 现状 | 目标 |
|---|---|---|
| 1 | 左树 + 中间整屏表单 + 右帮助栏 | **左工程树 + 中模块配置树 + 右表单** 三栏 |
| 2 | 无模块页签 | 一级模块页签（可关闭）+ 二级顶级容器页签（带 `…` 溢出下拉） |
| 3 | 树只显示实例 | 容器与实例**混排同树**，实例带 `i` 图标 |
| 4 | 参数逐个表单项，无启用开关 | 可选参数带**复选框**，未启用灰显；必填用**红标** |
| 5 | 数字输入无进制 | 数字输入 + **DEC 进制下拉** |
| 6 | 引用用下拉 | 引用用 **`--` 只读输入 + 选择图标按钮**（弹窗待核实） |
| 7 | 无面包屑 | 表单顶部**面包屑**（实例路径） |
| 8 | 无右键菜单 | 工程树右键菜单（本轮先做可见 11 项，子菜单留空占位并标未核实） |
| 9 | 无模块管理 | **双栏模块管理弹窗**（左树 ↔ 右表格，含生成/验证列） |
| 10 | 表单平铺 | 参数按**细线分组**（实例名称 / 参数 / 引用） |

## 六、验收方式（可执行）

1. **同视口并排**：1366×768 与 1400×900 各截一张，与本 spec 的 02 图并排，逐项核：三栏宽度、页签两级、树混排、表单行序、控件形态
2. **不写死模块**：把 `bswmd/` 换成最小 Dcm 样本，界面应同样渲染，且源码内 grep 不到 `CanIf`/`Dem` 字段名
3. **交互可达**：新增实例、勾选可选参数、切进制、关闭模块页签、打开模块管理弹窗，操作链路可走通
4. 未核实项必须在界面上**有明确占位或 tooltip**，不得假装已实现
